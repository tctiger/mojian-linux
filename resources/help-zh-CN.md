# 墨笺 Linux 1.0.0 中文使用帮助

原生 C++ / Qt 6 Markdown 编辑器。以 macOS 墨笺 3.11.1 为功能基线，编辑界面使用原生文本和表格控件。按 F1 打开本帮助，可搜索关键词、选择章节。帮助随应用离线提供。

## 1. 开始写作

启动后直接进入空白编辑界面，无须先选择“新建文档”。Ctrl+N 每次新建一个窗口，Ctrl+O 打开文件；再次打开同一文件会切回已有窗口。命令行支持 `mojian 文件.md` 和同时打开多个文件。

实时模式在排版正文中输入 Markdown。格式标记保留在源文件里，显示层隐藏常用标记；可随时切换源码检查。新窗口默认实时编辑。

## 2. 保存、编码与关闭

Ctrl+S 保存，Ctrl+Shift+S 另存为。支持读取 UTF-8、UTF-8 BOM、UTF-16 LE/BE BOM。保存统一使用 UTF-8；已有 CRLF 换行保留，新文件使用 LF。无法识别的编码会提示，原文不会被覆盖。

保存通过临时文件进行原子写入，失败后文档仍保留未保存状态。Ctrl+W 关闭当前窗口，Ctrl+Q 关闭应用；有修改时选择保存、放弃或取消。

同一目标文件已经在另一窗口打开时会阻止覆盖。个人文档与程序安装目录分开保存，发布归档不能代替文档备份。

## 3. 外部修改与恢复

程序监听当前文件。磁盘文件变化时，未修改且不在输入法组合输入中的文档可以重新载入；已有修改时保留编辑内容并提示。保存前再次比较磁盘摘要，检测到冲突时询问是否覆盖；也可取消后另存为再比较。

修改中的文档约每 15 秒生成本机恢复记录。异常退出后，下次不带文件参数启动会询问恢复。恢复后应尽快保存。成功保存或正常放弃关闭会清除对应记录；恢复不是每个按键都写盘。

恢复目录位于用户数据目录 `Mojian/mojian/recovery`；设置通常位于 `~/.config/Mojian/mojian.conf`，实际位置遵循 XDG 环境变量。恢复内容仅保存在本机用户目录。

## 4. 四种模式

| 快捷键 | 模式 | 用途 |
| --- | --- | --- |
| Ctrl+Alt+1 | 实时编辑 | 排版正文中输入，格式源码保留 |
| Ctrl+Alt+2 | 源码与预览 | 左侧源码、右侧原生排版 |
| Ctrl+Alt+3 | 仅源码 | 精确查看所有标记和复杂结构 |
| Ctrl+Alt+4 | 阅读 | 只读排版 |

分栏宽度可拖动，设置中可以启用同步滚动。结构块使用原生投影，常用行内格式直接在正文编辑。双击代码、公式或图表块进入原生块内容编辑器，即时写回，Esc 返回排版；块内编辑源内容。

## 5. 标题、段落与横线

标题使用一至六个 `#` 加空格，Ctrl+1 至 Ctrl+6 设置，Ctrl+0 恢复普通段落。Setext 标题也参与大纲。

```markdown
# 一级标题

普通段落。

---

另一段。
```

独占一行的 `---`、`***`、`___` 表示分隔线，与前文空一行可避免被解释为标题。文字下紧接 `---` 是二级标题。围栏代码中的横线保持代码。

空行分隔段落；普通一次换行为软换行。行末两个空格或反斜杠表示硬换行。

## 6. 粗体、斜体与其他行内格式

```markdown
**粗体**  *斜体*  ***粗斜体***  ~~删除线~~
`代码`  ==高亮==  x^2^  H~2~O  <u>下划线</u>
[链接文字](https://example.com)
```

Ctrl+B、Ctrl+I、Ctrl+U、Ctrl+Shift+X 分别切换粗体、斜体、下划线和删除线。选中文字后操作会添加或移除标记；实时模式无选区时设置随后输入的格式，空操作不会留下空标记。已在相同格式结尾时再次切换，可继续输入普通文字。

支持嵌套格式、常用转义和实体。反斜杠转义如 `\*星号\*`；行内代码不解释其中标记。中文斜体取决于字体和 Qt 的字形合成，与预览均使用原生排版。

## 7. 列表、任务与引用

无序列表使用 `- `、`* ` 或 `+ `，有序列表使用 `1. `。任务写作 `- [ ] 未完成` 或 `- [x] 已完成`，实时模式可以点击复选框。

引用使用 `> `。支持嵌套列表、引用、围栏代码，惰性续行和制表符缩进。菜单“段落”提供列表、任务和引用命令。

列表末尾回车续写下一项，有序编号递增；空项回车退出，任务续写默认未完成。Tab 缩进，Shift+Tab 减少缩进；选中多行时整段处理。Ctrl+] / Ctrl+[ 也可调整缩进。

## 8. 代码、公式与图表块

代码块使用三个以上反引号或波浪号，之后可写语言名。Ctrl+Shift+K 插入代码围栏；在开放围栏末尾回车可以补齐闭合围栏。代码内不执行脚本，也不续写列表。

双击排版块编辑内容，修改立即进入正文撤销历史。Esc 返回正文。若内容过于复杂，可切换源码模式。结构投影保留原始 Markdown，显示层不会把源文件改成富文本文档。

## 9. 内嵌富文本表格

扩展 Markdown 或 GFM 中可输入：

```markdown
| 项目 | 数量 |
| :--- | ---: |
| **苹果** | 3 |
```

已完成的表格显示原生单元格，双击编辑，可使用常用格式、链接、公式等行内排版。字段内编辑直接写回源文，保存包含正在编辑的字段。手动输入尚未完成的表格时先保留源码，离开后投影，避免打断输入。

Ctrl+Alt+T 插入或编辑表格，独立表格窗口在确定时提交，取消不改变文档。控制区提供增删行列、上下左右移动、当前列对齐、合并与拆分。

Tab / Shift+Tab 按单元格前后移动；Return / Shift+Return 上下移动；越过最后一行时追加行。Esc 结束字段编辑。正文表格使用共同的撤销历史，一轮连续整表修改可单步撤销。

## 10. 表格合并与源码

选择相邻矩形区域后合并；拆分后文字保留在左上格。表头不与下方数据行纵向合并。会破坏合并矩形或文字锚点的重排会被拒绝。

普通表格保存为管道 Markdown；合并表格保存为 HTML table。生成的单元格携带原始 Markdown 元数据，保留公式和富文本以便再次编辑。外部工具删除这些属性后可能只能恢复其 HTML 文字。

竖线和反斜杠写回时转义。表格不支持任意 HTML/CSS 布局，复杂导入表格建议先复制文档再调整。列数、行数和渲染尺寸设有保护限制。

## 11. 链接、脚注、提示与目录

Ctrl+K 插入链接。支持直接链接和引用式链接：

```markdown
[网站][site]

[site]: https://example.com "说明"

正文脚注[^note]。

[^note]: 脚注可以包含多段落和嵌套结构。
```

扩展模式支持脚注、提示块、`[TOC]` 自动目录、上标/下标/高亮。提示示例：

```markdown
> [!WARNING]
> 注意这里的说明。
```

目录根据当前标题生成。阅读区可打开链接及定位标题；链接地址应由使用者确认。

## 12. 数学公式与本地宏

行内使用 `$x_1^2$`，块级公式使用独占行的 `$$` 开始和结束。

```markdown
$$
\frac{-b\pm\sqrt{b^2-4ac}}{2a}
$$
```

支持常用分数、根式、上下标、二项式、数学符号、字体、重音、矩阵、cases、align、array 和基础 `\ce{H2O -> H2 + O2}`。

“设置 → 数学”可保存 `\newcommand` / `\renewcommand` 本地宏，最多三个位置参数，有递归与长度保护。公式应用于实时显示、阅读和原生导出。

不是完整 TeX、MathJax 或 mhchem；不提供完整宏包、所有环境或可选默认参数。不支持的公式保留原文，可用外部工具生成图片。

## 13. Mermaid 图表

在 mermaid 围栏中输入：

```mermaid
flowchart LR
A[编写] --> B{检查}
B -->|通过| C[保存]
```

支持流程图、基础时序图、类图、状态图、饼图、甘特图。流程图包含方向、链式分支、常见形状、分组和基础样式；Graphviz 可用时用于布局，无须联网。

时序图支持基础参与者与消息，类图/状态图支持基础关系与起止点。甘特图支持日期、d/h/w 时长、依赖、分区和里程碑。

与 mac 版相同，不是完整 Mermaid：不执行 click/脚本，不支持所有 CSS、alt/loop/激活、复杂状态、全部配置或所有图表类型。未知内容保留源码。

## 14. 图片、粘贴与尺寸

Ctrl+Shift+I 选择本地图片。文档已有路径时尽量使用相对路径；拖入图片或粘贴剪贴板图片可插入附件。相对路径以 Markdown 文件所在目录为基准，传送文档时须一起传送附件。

```markdown
![说明](images/photo.png)
![远程图片](https://example.com/photo.png)
![指定宽度](images/photo.png){width=320}
```

“格式 → 图片设置”编辑路径、说明及宽度。网络图片异步加载并缓存；断网或下载失败时保留链接。无裁剪与完整附件库管理。

## 15. 主动上传图片

“设置 → 图片上传”填写 HTTPS 地址、multipart 字段（默认 file）、JSON URL 路径（默认 data.url）和认证前缀。返回示例：`{"data":{"url":"https://example.com/a.png"}}`。

令牌通过“保存令牌到系统钥匙环”写入 Secret Service，需要 secret-tool 和可用钥匙环。设置文件不明文保存令牌；留空保留原值。

“格式 → 上传图片”主动选择文件后才上传，单张上限 25 MB，可取消。响应成功且原目标仍有效时插入返回链接。仅允许 HTTPS，开发测试允许本机回环 HTTP；不自动上传粘贴图片，不自动跟随未知重定向。

需自行配置兼容服务，网络和服务认证错误会提示。程序不包含公共图床账号。

## 16. 查找、替换与跳转

Ctrl+F 查找，Ctrl+H 查找替换，可区分大小写、全字、正则和仅选区。下一处/上一处循环查找，查找框 Return 查下一处。Ctrl+L 按源码行号跳转。

单次和全部替换支持撤销；全部替换是一组记录。空查找不执行，无效正则提示。正则替换使用 `$1` 至 `$99` 引用捕获组，`$$` 表示字面美元符。

例如查找 `(苹果)(\d+)`，替换 `$1-$2`。全字按 Unicode 字母、数字、下划线边界识别，不是中文分词。

## 17. 大纲、文件夹与长文档

大纲包含 ATX 和 Setext 标题，点击定位；代码围栏中的伪标题不计入。显示菜单可隐藏大纲和文件夹侧栏。

“文件 → 打开文件夹”显示 Markdown/文本文件树，双击打开并避免同一文件重复窗口。目录监听会刷新变动；有文件数量和目录监听上限。

解析快照、缓存、合并刷新、后台字数统计及有界增量解析减少重复工作。涉及引用定义、未闭合围栏等全局结构时会完整解析。大文件、极深嵌套和图像尺寸仍有资源保护，不承诺所有操作均为局部复杂度。

## 18. 主题、字号与写作辅助

Ctrl+逗号打开设置。可选择跟随系统、浅色、深色、护眼、Solarized 或自定义主题，调整字号与行距，开关行号、括号配对、拼写检查和同步滚动。

显示菜单提供专注模式、打字机模式、主题导入/导出。专注模式突出当前段落，打字机模式使输入位置接近视口中心。

主题为原生 JSON 配置，包含颜色、字体/间距等可支持字段。无效颜色和不合理范围会被拒绝；不兼容任意 CSS 主题。英文拼写检查使用 Hunspell 和随包词典，右键可选建议；不进行中文语法纠错。

## 19. 原生导出与打印

“文件 → 导出”支持 PDF、HTML、纯文本和 RTF。Ctrl+P 使用原生打印对话框，需要可用打印服务或设备。

PDF 使用纸面配色并添加标题书签；RTF 保留常见文字格式、表格、图片与链接。HTML 由原生富文本文档生成，公式和图表可嵌为 PNG；本地/远程附件仍可能需要一并携带。

纯文本导出排版文字，不等于保存 Markdown。分页和字体受 Linux 字体环境影响，重要文档导出后应检查。不是浏览器级 HTML/CSS 排版。

## 20. Pandoc 导入和转换

导出 Word（DOCX）、EPUB、ODT、reStructuredText、MediaWiki 和 LaTeX 使用 Pandoc。“文件 → 导入 Word / RTF / EPUB”也调用 Pandoc，转换结果在新窗口打开，不覆盖原文件。

优先查找 PATH 中的 pandoc，也支持 `~/.local/lib/mojian/bin/pandoc`。可安装配套私有 Pandoc，避免更改系统版本。缺失时提示安装，不会假装转换成功。

复杂办公文档可能丢失特殊布局，导入图片不会自动建立完整附件库。LaTeX 导出是源码，生成 PDF 所需 TeX 环境另行配置。

## 21. 标准、语言与能力边界

设置中有扩展 Markdown、严格 CommonMark 0.31.2、严格 GFM 0.29。严格模式使用与 mac 版相同的固定版本 C 解析器，公开规范 HTML 序列化测试覆盖 652 个 CommonMark 与 677 个 GFM 例子。扩展模式另行支持公式、脚注、提示、高亮等。

规范解析一致不表示原生排版与网页逐像素相同。HTML 使用受限原生显示，未知元素可回退源码，不执行 JavaScript，也不提供任意网页/CSS 编辑。复杂语法可切源码精确处理，嵌套深度有保护上限。

界面跟随系统语言，支持简体中文、繁体中文、英语、日语、德语、法语、西班牙语，也可在设置中选择。语言重启后完整生效，中文帮助始终可用。原生文件/打印窗口的部分文案由 Qt 和桌面系统提供。

## 22. 快捷键、输入法与排障

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 / 保存 | Ctrl+N / O / S |
| 另存为 / 关闭 / 退出 | Ctrl+Shift+S / Ctrl+W / Ctrl+Q |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y，以菜单为准 |
| 粗体 / 斜体 / 下划线 | Ctrl+B / I / U |
| 删除线 / 链接 / 图片 | Ctrl+Shift+X / Ctrl+K / Ctrl+Shift+I |
| 标题 / 普通段落 | Ctrl+1…6 / Ctrl+0 |
| 代码块 / 表格 | Ctrl+Shift+K / Ctrl+Alt+T |
| 查找 / 替换 / 行号 | Ctrl+F / Ctrl+H / Ctrl+L |
| 实时 / 分栏 / 源码 / 阅读 | Ctrl+Alt+1 / 2 / 3 / 4 |
| 设置 / 打印 / 帮助 | Ctrl+逗号 / Ctrl+P / F1 |

开发验证环境使用 X11/i3 与 fcitx5，应用沿用桌面输入法配置，不修改全局环境。组合输入期间延后投影和保存，避免候选文字进入源文件。自动事件回归不能替代每种第三方输入法候选窗的人工体验。

横线不显示时，检查是否紧接上一行文字（Setext 标题）、位于代码块或 YAML 头中。表格不显示时检查分隔行与当前语法模式。保存失败检查目录权限和空间；冲突时另存为保留两个版本。

“帮助 → 关于墨笺”查看版本及构建时间，`mojian --version` 也可查看。反馈请提供版本、发行版、Qt 版本、桌面、编辑模式、不含隐私的最小 Markdown 和复现步骤。第三方许可证在帮助菜单中离线查看。
